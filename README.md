## 🚀 Stack e foco
- **Front-end:** Vue 3 (Composition API), **Nuxt (SSR/SSG/Hybrid)**, Pinia, VueUse, Nuxt Image/SEO, TailwindCSS + UI libs.
- **Back-end:** **Node.js** (Express / H3 / Nitro), TypeScript, Autenticação (JWT/Session), REST/GraphQL, WebSockets.
- **Dados:** PostgreSQL, Mysql, Prisma/Drizzle, Redis, Supabase; migrações, seeds e rotinas de ETL simples.
- **DevOps:** Docker, CI/CD (GitHub Actions), Nginx/Deploy em VPS, métricas básicas e logs.
- **Qualidade:** ESLint/Prettier, Vitest/Playwright, análise de bundle e performance (Lighthouse/Nitro).
